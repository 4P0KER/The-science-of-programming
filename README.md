# Engine Wrapper
Проект реализует систему инкапсуляции методов класса произвольной сигнатуры с возможностью регистрации и выполнения команд через единый интерфейс.
Система поддерживает значений аргументов по умолчанию, проверки типов аргументов и возвращаемых значений и обработки исключений и ошибок времени выполнения
## Требования
- Компилятор C++ с поддержкой стандарта C++17
- CMake 3.10 или выше
- MSVC (Visual Studio 2019+) или MinGW-w64

## Архитектура
### Основные компоненты
**ICommand** - Базовый интерфейс всех команд
- `execute()` - выполнение команды
- `get_parameter_names()` - получение имен параметров

**MethodWrapper** - Шаблонная обертка методов класса
- Поддерживает методы с произвольной сигнатурой
- Обрабатывает значения по умолчанию
- Выполняет проверку типов аргументов

**Engine** - Движок управления командами
- Регистрация и удаление команд
- Выполнение команд по имени
- Управление жизненным циклом команд
### Вспомогательные структуры
- **VoidResult** - Специальный тип для void-методов
- **create_wrapper()** - Фабричная функция для создания оберток
## Особенности реализации
### 1. Типобезопасность
- Использование `std::any` для передачи аргументов и результатов
- Проверка типов во время выполнения через `std::any_cast`
- Компиляция с включенными предупреждениями (`/W4` для MSVC)

### 2. Гибкость параметров
- Именованные аргументы (порядок не важен)
- Значения по умолчанию для всех параметров
- Поддержка произвольного числа параметров

### 3. Обработка ошибок
- Проверка дублирования аргументов
- Обработка исключений из методов

### 4. Управление памятью
- Использование `unique_ptr` для владения командами
- Безопасная работа с указателями

## Возможности проекта
### Поддерживаемые методы
- Методы без параметров
- Методы с произвольным числом параметров
- Методы с разными типами возвращаемых значений
- Void-методы
- Константные методы
### Управление командами
- Регистрация команд с уникальными именами
- Удаление команд
- Очистка всех команд
- Получение списка команд
- Запрос параметров команды

### Особенности выполнения
- Выполнение с явным указанием типа результата
- Автоматическое приведение аргументов
- Проброс исключений из методов
- Проверка всех аргументов перед выполнением
## Пример использования
```C++
void test_basic_functionality() {
    TestSubject subj;
    auto wrapper = create_wrapper(&subj, &TestSubject::multiply,
                                 {{"arg1", 0}, {"arg2", 0}});
    
    Engine engine;
    engine.register_command("command1", std::move(wrapper));
    
    int result = engine.execute_as<int>("command1", {{"arg1", 4}, {"arg2", 5}});
    std::cout << "  command1(4, 5) = " << result << std::endl; //20
}
```
